# 组织与用户权限 POC

单文件离线 HTML 原型，覆盖组织筛选、用户管理、用户列表批量操作，以及知识库实例成员授权示例。

## 打开方式

### 方式一：直接打开

用浏览器打开 `index.html`。

### 方式二：本地静态服务

```bash
python3 -m http.server 4173 --directory "/Users/rio/Desktop/零散文件/org-admin-poc"
```

访问 <http://localhost:4173/>。

## POC 范围

### 组织与用户

- 左侧组织树仅作为用户筛选条件：公司、子公司、可多级部门、岗位。
- 右侧用户列表展示当前筛选结果；组织节点不直接承载权限。
- 用户最终绑定岗位和一个或多个角色。
- 用户列表支持批量赋予角色、批量回收角色、批量转岗；操作只作用于当前勾选用户，默认不全选。
- 回收角色前校验用户至少保留一个角色；系统只报错，不自动补默认角色。
- 批量转岗只修改岗位，不新增或回收角色；岗位没有权限粘性，新用户不会继承历史批量操作。

### 知识库权限示例

- 资源权限保留“单个添加”和“按组织筛选添加”两个入口。
- 单个添加：输入搜索词后展示匹配用户详情，再选择用户和资源角色。
- 按组织筛选添加：先选择组织节点，再在成员列表中勾选用户；不提供用户搜索框。
- 组织节点只负责筛选，确认后仍按用户逐个写入资源成员权限；默认不全选。
- 已有成员不会重复添加，创建者固定为所有者。

